# Code of conduct

This project exists to make Linux audio software easier to install. Everything
else — who you are, how long you have used Linux, whether your first pull
request is perfect — is beside the point.

## What is expected

Assume the other person is trying to help. Most disagreements here are about
packaging, security trade-offs or someone else's build system, and almost none
of them are about the person you are talking to.

Be specific. "This breaks on Fedora 41 because the bundle ships a `.so` built
against glibc 2.40" is useful; "this is broken" is not. The same goes for
review: say what you would change and why.

Take a correction the way you would want one taken. Being wrong about an
archive layout is not an insult, and neither is being told so.

## What is not

- Harassment, insults or personal attacks, in issues, pull requests, commit
  messages or anywhere else this project is discussed.
- Unwelcome attention of a sexual nature, and sexualised imagery.
- Publishing someone's private information — address, workplace, legal name,
  anything they have not published themselves.
- Deliberate disruption: derailing threads, reopening settled decisions to
  wear people down, or submitting contributions in bad faith.
- Anything that tries to get code onto a user's machine that the user did not
  ask for. A manifest that points at a tampered artifact is not a difference
  of opinion; see [SECURITY.md](SECURITY.md).

## Scope

This applies wherever the project is: this repository, the registry
repository, and any space where someone is representing the project.

## Enforcement

Report a problem privately to <savashn@proton.me>. Reports are read by the
maintainers, kept confidential, and answered. Say what happened and where; a
link is usually enough.

Maintainers may edit or remove comments, close issues and pull requests, and
block accounts. A first response is normally a private word; repeated or
deliberate behaviour is met with a block, without a warning if the behaviour
is severe enough on its own.

Maintainers who do not follow this document are subject to it like anyone
else, and a report about one goes to the others.
